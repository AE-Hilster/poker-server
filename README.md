# Poker Server
This is a fully functional, proof of concept, Poker backend server created by Elliott HIll using Express and Socket.io to be used with this [Poker Client](https://github.com/AE-Hilster/poker-client). More information on this project can be found [here](https://www.mrhilster.com/project/poker/).
## Features
- Name customisation.
- Custom lobbies/rooms.
- Data persistence on disconnection.
- Complete game loop with hands correctly evaluated and pots split on draws.
## Feature Roadmap
- Time players out and force-fold them from the game on disconnection.
- Correct betting order after pre-flop betting round.
- Customise blinds in custom lobbies.
- Data storage in a database.
